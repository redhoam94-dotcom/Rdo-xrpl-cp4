Apa itu Pemrograman?

Pemrograman adalah proses memberikan instruksi kepada komputer untuk menyelesaikan masalah secara logis. Komputer bekerja berdasarkan urutan langkah (Algoritma) yang ditulis menggunakan Bahasa Pemrograman.

Analogi: Resep Masakan

Algoritma mirip seperti resep makanan. Jika langkah-langkahnya acak, masakan bisa gagal atau rasanya berbeda.

Penerjemah Masalah

Programmer merancang alur berpikir logis dari masalah nyata menjadi instruksi mesin yang efisien.

Tingkatan Bahasa

Bahasa Tingkat Rendah (Biner/Assembly) dipahami langsung mesin, sedangkan Bahasa Tingkat Tinggi (Python, JS, Java) mudah dibaca manusia.

2. SET nilai_siswa = 80
3. SET kkm = 75

5.     SET status = "Tuntas / Lulus"
6. ELSE
7.     SET status = "Remedial"
8. PRINT status
9. SELESAI
